# Balam

Demonio original, comandante infernal. La fuente no fija su edad aparente.

## Identidad inmutable

- Rostro: tres rostros furiosos que rotan lentamente alrededor del cuello, cada uno con una expresión distinta de rabia.
- Cuerpo de 2,15 m, complexión masiva y robusta, postura constante de tensión contenida e inquietud.
- Cicatrices de tormenta que cubren el cuerpo y destellan con chispas de electricidad azul estática.
- Vestuario canónico: armadura pesada de hierro tachonado con púas oscuras; paleta dominante de azul tormenta, amarillo eléctrico y gris hierro.

El pelo, los ojos y las alas no están definidos por la fuente.
