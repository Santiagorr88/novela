# Leraje

Capitana demoníaca, arquera de veneno. La fuente no fija su edad aparente.

## Identidad inmutable

- Cuerpo de 1,85 m; la luz resbala sobre ella igual que resbala sobre la piedra.
- `Mors`: arco que lleva colgado con soltura sobre un hombro.

El vestuario no está definido por la fuente y debe especificarse por plano.
