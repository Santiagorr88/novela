# Gusion

Capitán demoníaco de Política Mortal. La fuente no fija su edad aparente.

## Identidad inmutable

- Cuerpo de 1,98 m, hombros estrechos.
- `Veritas Inversa`: pluma que sostiene sin fuerza entre dos dedos, girándola con indolencia.

El vestuario no está definido por la fuente y debe especificarse por plano.
