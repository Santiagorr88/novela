# Malthus

Capitán demoníaco de Rituales Oscuros. La fuente no fija su edad aparente.

## Identidad inmutable

- Cuerpo de 1,95 m.
- Armadura con una manga de sarga en el antebrazo.
- Hoja de hierro que porta para cortes rituales.
- Estuche metálico para transportar informes sellados.
- `Maleth`: tiza ritual guardada bajo la manga de sarga.
