# Forma demoníaca

Forma actualmente documentada y representada por las referencias canónicas.

Mantiene el mismo rostro hermoso e inmaculado, piel pálida, pelo blanco plateado y ojos rojo vino. Sus alas negras absorben visualmente la luz cercana sin emitir resplandor, fuego, humo ni partículas. No se añaden cuernos, armadura, corona, joyas o arma salvo que una fuente narrativa posterior los establezca.
