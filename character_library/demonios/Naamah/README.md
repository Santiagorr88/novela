# Naamah

Comandante demoníaca de Manipulación Social, Duquesa del Engaño. La fuente no fija su edad aparente.

## Identidad inmutable

- Forma femenina grácil de 2,00 m.
- Piel gris perlado.
- Pelo que ondula como humo, en movimiento lento y constante.
- Sin vestuario fijo: `Neriah`, un velo vivo, se ciñe al cuerpo y puede reconfigurar su propia silueta para pasar por ropa ordinaria.
- Neriah se lleva ceñido contra la piel o enrollado sobre un hombro cuando no está dando forma a una ilusión.
