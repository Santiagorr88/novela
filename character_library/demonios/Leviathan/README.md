# Leviathan

Señor Infernal de los Instintos. La fuente no fija su edad aparente.

## Identidad inmutable

- Cuerpo titánico reptiliano de 2,30 m.
- Recubierto de escamas negro medianoche.
- Ojos ciegos.
- Colmillos eternos; garras con punta de veneno.
- Sin vestuario ni armadura: la fuente no describe ninguna prenda.
