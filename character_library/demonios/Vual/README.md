# Vual

Entidad demoníaca, Capitán y seductor de almas reencarnadas. La fuente no fija su edad aparente.

## Identidad inmutable

- Cuerpo de 1,85 m de altura.
- Guantes.
- La cadena DESEUM, una fina costura de cadena llevada en la muñeca, oculta bajo la manga hasta que se manifiesta.

## Vestuario y accesorio

- Ropa fina de mortal, a medida.
- Guantes.
