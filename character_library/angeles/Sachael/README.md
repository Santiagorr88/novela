# Sachael

Capitán, Guardián del Relámpago. Edad aparente no especificada por la fuente.

## Identidad inmutable

- Cuerpo de 1,90 m de altura; llega y se mueve como llega el relámpago, todo de golpe.
- El rostro, los ojos, el pelo y el vestuario no están definidos por la fuente. Esta ficha es intencionadamente mínima en vez de inventada; toda referencia visual se apoya en `canonical/body_reference.png` y las imágenes de apoyo.

## Referencias

- `canonical/face_reference.png`: autoridad para rostro (la fuente no define rasgos faciales; generado a partir de la referencia maestra del autor).
- `canonical/body_reference.png`: autoridad para altura, proporciones y vestuario tal como fueron aportados por el autor.
- `supporting_references/expressions.png` y `turnaround.png`: apoyo secundario.

Las fuentes originales permanecen en `video_production/images_personajes/angeles/sachael/`.
