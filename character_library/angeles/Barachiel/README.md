# Barachiel

Capitán celestial adulto de las Comunicaciones Angélicas. Edad aparente no especificada por la fuente.

## Identidad inmutable

- Altura de 1,88 m.
- Alas presentes, acordes a su rango; color, envergadura y plumaje exactos no especificados por el canon.

## Vestuario y accesorio

- Túnicas de sarga, lisas, sin placas de armadura ni ornamento.
- Pergamino de sarga, llevado medio desenrollado contra el antebrazo.
