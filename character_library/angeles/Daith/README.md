# Daith

Archivero celestial del Juicio. Edad aparente y rasgos faciales no especificados por la fuente.

## Identidad inmutable

- Marca distintiva: la tinta fluye visiblemente por sus venas, apenas visible bajo la piel.

## Vestuario y accesorio

- Capa confeccionada con fragmentos de pergamino.
- `Scriptura`: la lanza-pluma, llevada en posición vertical en reposo.

## Referencias

- `canonical/face_reference.png`: autoridad para rostro y marca de tinta visible.
- `canonical/body_reference.png`: autoridad para proporciones, capa de pergamino y Scriptura.
- `supporting_references/expressions.png` y `turnaround.png`: apoyo secundario.

Las fuentes originales permanecen en `video_production/images_personajes/angeles/daith/`.
