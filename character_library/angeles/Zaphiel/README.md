# Zaphiel

Entidad angelical, Capitán de Iluminación Violenta. La fuente no fija su edad aparente.

## Identidad inmutable

- Cuerpo de altura aparente 1,95 m; siempre se mantiene el más erguido entre sus pares, con una quietud rígida y disciplinada.
- Ojos de mirada pálida.

Rostro, pelo y vestimenta más allá de lo anterior no están descritos en ninguna fuente narrativa; quedan a discreción del diseño. Las referencias canónicas fijan esa apariencia para mantener la continuidad visual, pero no adquieren por ello autoridad de canon narrativo.

## Referencias

- `canonical/face_reference.png`: autoridad para rostro, pelo y ojos tal como quedaron fijados en el diseño.
- `canonical/body_reference.png`: autoridad para proporciones, armadura y alas.
- `supporting_references/expressions.png` y `turnaround.png`: apoyo secundario.

Las fuentes originales permanecen en `video_production/images_personajes/angeles/zaphiel/`.
