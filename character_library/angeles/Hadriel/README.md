# Hadriel

Capitana celestial, Vigilante del Velo. Presentada como femenina (ella) en el texto fuente; edad aparente no especificada.

## Identidad inmutable

- Altura aparente: 1,93 m.

La fuente no describe su rostro, pelo, ojos, complexión ni vestuario más allá de esto; este perfil es intencionadamente mínimo en vez de inventar rasgos.
