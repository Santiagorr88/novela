# Forma celestial — vigente

Forma actualmente documentada y representada por las referencias canónicas de `character_library/Camael/canonical/`.

Mantiene las runas místicas carmesí grabadas en el torso desnudo, los ojos color rayo azul, la cicatrización severa en la espalda donde las alas fueron quemadas en las Puertas de Ónice (sin alas emplumadas), y las grebas de bronce abollado con falda de cuero siena. No se añaden alas, armadura adicional ni arma salvo que una fuente narrativa posterior los establezca.
