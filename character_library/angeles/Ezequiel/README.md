# Ezequiel

Capitán celestial adulto y maestro de armas antiguas.

## Identidad inmutable

- Altura de 1,95 m, porte rígido y disciplinado; complexión no especificada por la fuente.
- Porte formal y ceremonioso, expresión disciplinada y controlada; más rasgos faciales no especificados por la fuente.

## Vestuario y accesorio

- Vestuario no especificado por la fuente más allá de una vaina que porta al costado para su espada.
- `Memoria`: espada llevada envainada al costado, desenvainada en un único movimiento fluido.
