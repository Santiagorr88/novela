# Jahiel

Capitán celestial de la Hueste Celestial bajo el mando de Raziel, purificación física. Edad aparente: adulta.

## Identidad inmutable

- Cuerpo de 1,88 m.
- Viste una túnica blanca lisa.

## Accesorio inmutable

- `CAELUM`: espada que solo cercena la corrupción, portada cerca del cuerpo, envainada a voluntad.

La fuente no describe su rostro, pelo ni ojos más allá de estos rasgos.
