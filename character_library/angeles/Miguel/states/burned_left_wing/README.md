# Estado opcional — ala izquierda quemada

Este estado no forma parte de la apariencia celestial base. Solo se activa cuando la continuidad de una escena lo exige.

- El daño pertenece al ala IZQUIERDA de Miguel.
- De frente aparece a la DERECHA del espectador.
- De espaldas aparece a la IZQUIERDA del espectador.
- El ala conserva la construcción blanco perla de la forma base junto al cuerpo, pasa a gris ceniza y termina negra hacia la punta.
- La rotura y la pérdida de plumas se concentran en el último tercio; la mayor parte del ala sigue blanca.
- Es daño antiguo, frío y muerto: sin fuego, brasas, humo, naranja ni resplandor.
- El ala derecha permanece blanca, intacta y perfectamente emplumada.
- Rostro, ojos, armadura, emblema cian, faldones y materiales permanecen idénticos a la forma celestial base.
