# Elom

Líder celestial adulto de escuadrón, coordinador de sinergia. Altura, edad aparente y rasgos faciales no especificados por la fuente.

## Vestuario y accesorio

- Placas de armadura entrelazadas, engastadas con nodos místicos luminosos, diseñadas como punto de convergencia místico para las energías compartidas del escuadrón.
- `Chordis`: guantelete llevado en una mano y antebrazo, que enlaza la fuerza vital de los aliados en ritmos compartidos; sus nodos chisporrotean y se apagan cuando sufre daño crítico, mostrando hilos rotos de conexión mística.

## Referencias

- `canonical/face_reference.png`: autoridad para rostro.
- `canonical/body_reference.png`: autoridad para proporciones, armadura y Chordis.
- `supporting_references/expressions.png` y `turnaround.png`: apoyo secundario.

Las fuentes originales permanecen en `video_production/images_personajes/angeles/elom/`.

> Nota: `identity_lock.txt` de origen no especifica rasgos faciales, altura ni color de pelo/ojos para Elom; solo documenta vestuario y accesorio. Las imágenes de referencia son la única autoridad para esos rasgos hasta que el canon los fije por escrito.
