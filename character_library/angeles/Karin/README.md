# Karin

Líder de escuadrón celestial, enlace de sinergia. Edad aparente no especificada por la fuente.

## Identidad inmutable

- Pelo trenzado de luz tejida.
- Manos tatuadas con glifos de unión.

La fuente no describe su rostro, ojos, altura ni vestuario más allá de estos rasgos. (Fuente: L2/05.)
