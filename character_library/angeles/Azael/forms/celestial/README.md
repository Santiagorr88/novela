# Forma celestial (equilibrada) — vigente

Forma actualmente documentada y representada por las referencias canónicas de `character_library/Azael/canonical/`.

Mantiene el rostro simétrico tallado en basalto oscuro con vetas de oro, la división vertical exacta oro/negro estrellado, los ojos asimétricos y las dos alas rígidas de placas de basalto. No se añade pelo, armadura, corona, joyas ni arma salvo que una fuente narrativa posterior los establezca.

Nota: la fuente reconoce un estado degradado — `Azeloth`, un vacío que absorbe fe y luz si Azael muere sintiéndose inútil o abandonado. Ese estado no está representado en las referencias actuales y no debe inferirse automáticamente.
