# Cassiel

Capitán celestial adulto, explorador espiritual. Edad aparente no especificada por la fuente.

## Identidad inmutable

- Rasgos faciales no especificados por la fuente; expresión meditativa, con la mirada baja constante.
- Altura de 1,90 m, complexión ordinaria sin rasgos distintivos.
- Ojos de un azul apagado y mate.
- Alas de plumas gris ratón, plegadas ceñidamente contra la espalda.

## Vestuario y accesorio

- Túnica sencilla de sarga gris ceniza, sin placas de armadura ni ornamento.
- Paleta dominante: gris ceniza, plata apagada y pizarra.
