# Raziel

Comandante, Portador del Conocimiento Prohibido, Guardián de las Llamas Esotéricas. Edad aparente no especificada por la fuente.

## Identidad inmutable

- Rostro no descrito por la fuente más allá de los ojos.
- Cuerpo de 2,00 m de altura.
- Ojos: un calor contenido, como fuego guardado en reserva, ardiendo con sabiduría peligrosa.
- Marcas distintivas: una túnica cubierta de inscripciones inquietas — símbolos que visiblemente se reacomodan y cambian si se les mira demasiado fijo, sin quedarse nunca quietos.

## Vestuario y accesorio

- Túnica ardiente marcada de símbolos, con texto oculto y móvil.
